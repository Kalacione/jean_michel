# Sources of Truth Report

This report synthesizes key external data sources across various knowledge domains, detailing their utility, access methods, and specific added value.

| Candidate | Domain | Access Method | Added Value |
| :--- | :--- | :--- | :--- |
| **Wikidata** | Encyclopedic | API (SPARQL) | Highly structured, machine-readable facts and relationships. |
| **Wikipedia** | Encyclopedic | API (MediaWiki) | Broad coverage of topics and general knowledge. |
| **OpenAlex** | Scientific | API / Dataset | Comprehensive catalog of the global research system. |
| **Semantic Scholar** | Scientific | REST API | Exploration of scientific publications and citation networks. |
| **arXiv** | Scientific | Repository / Open Data | Access to electronic preprints and postprints. |
| **Zenodo** | Scientific | Repository / Open Data | Open repository for research data and software (CERN). |
| **PubMed** | Scientific | API | Specialized, curated biomedical and life sciences data. |
| **NewsAPI.ai** | News | API | Real-time and historical global news with sentiment analysis. |
| **NewsData.io** | News | API | Live-breaking news and large archived database. |
| **OpenStreetMap** | Geographic | API (Overpass) | Detailed, community-driven map features (roads, buildings). |
| **Geoapify** | Geographic | API | Simplified access to OpenStreetMap data. |
| **World Bank** | Statistical | API | Economic, financial, and social data for 200+ countries. |
| **IMF** | Statistical | API | Global economic data, forecasts, and stability metrics. |
| **data.europa.eu** | Governmental | Portal / Open Data | Consolidated access to EU institutions' open data. |
| **Data.gov** | Governmental | Portal / Open Data | US state and city open data. |
| **UN Open Data** | Governmental | Website / Open Data | Statistical data from UN member states and agencies. |
| **GitHub API** | Technical | API (REST) | Access to source code, metadata, and repository history. |
| **PyPI** | Technical | API / Data Dump | Catalog of Python libraries and package metadata. |
| **Stack Overflow API** | Technical | API | Real-world developer expertise and Q&A. |
| **systemanaturae.org** | Specialized | Dataset | Wildlife and animal species data. |
| **Neo4j** | Graph Technology | Graph Database | Tool for managing and querying graph-structured data. |
